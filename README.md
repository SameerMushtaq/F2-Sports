## 🛠️ Tech Stack & Hosting Options
- **Frontend**: HTML5, CSS3 (Modern Responsive Flex/Grid & Custom Design System), Vanilla JavaScript (Zero bloated frameworks, ultra fast).
- **Icons & Typography**: FontAwesome 6, Google Fonts (`Outfit` & `Plus Jakarta Sans`).
- **Payment Integration**: Native UPI QR Code Scanner & UTR validation interface.
- **Hosting Compatibility**:
  - **GitHub Pages**: Ready out of the box (`index.html`).
  - **Vercel**: Deploy instantly with 1-click via Git integration.
  - **Supabase (Optional)**: Can easily attach Supabase JS client for cloud orders & inventory persistence.

## 📦 Deployment Instructions

### 1. Host on GitHub Pages (Free)
1. Create a new repository on GitHub named `f2-sports`.
2. Upload `index.html` and `README.md`.
3. Go to **Settings > Pages > Branch: `main` > `/ (root)` > Save**.
4. Your site will be live at `https://<your-username>.github.io/f2-sports/`.

### 2. Host on Vercel (Free & Instant)
1. Push this repository to your GitHub account.
2. Go to [vercel.com](https://vercel.com) and click **Add New > Project**.
3. Import your `f2-sports` repository and click **Deploy**.
